[NOTE 01: Trailing-Zero Output Multiplicity and Tail Shift Analysis]
Originally Lemma 1 assertional defect:
In an arithmetic bit-serial adder evaluating x + 2x + 1:
The adder performs division by 2 on-the-fly by overwriting the first sum bit
(which is always 0 for 3*odd + 1) with blank $.
Consequently, for any odd integer n with valuation k = nu_2(3n + 1):
The number of trailing zeros written to tape is (k - 1), NOT k.

Modular Case Analysis:
Case 1: n = 3 (mod 4)
  Here 3n + 1 = 10 = 2 (mod 4), so nu_2(3n+1) = 1 (k = 1).
  The output word written to tape contains 1 - 1 = 0 trailing zeros!
  On the subsequent pass t, State A reads 0 trailing zeros and exactly 1 odd-core
  bit (b_0 = 1).
  Therefore, Delta_tail(N, t) = 1 (NOT 2).

Case 2: n = 1 (mod 4)
  Here 3n + 1 = 4 = 0 (mod 4), so nu_2(3n+1) >= 2 (k >= 2).
  The output word written to tape contains k - 1 >= 1 trailing zeros.
  On the subsequent pass t, State A consumes (k - 1) zeros plus 1 odd-core bit.
  Therefore, Delta_tail(N, t) = (k - 1) + 1 = k >= 2.

Conclusion:
Delta_tail(N, t) in {1, k}, taking value 1 whenever the previous state satisfies
T^{t-1}(N) = 3 (mod 4).

[NOTE 04: Transducer Operator Semantics: T(n) vs T_tilde(n)]
The machine M' does not compute the full multi-division Syracuse operator:
    T(n) = (3n + 1) / 2^{nu_2(3n+1)}
in a single physical pass.
Instead, it computes the accelerated dyadic affine map:
    T_tilde(n) = (3 * odd(n) + 1) / 2
The single factor of 1/2 is computed on-the-fly during binary addition.
The remaining (nu_2 - 1) divisions are manifested as (nu_2 - 1) trailing zeros
on the tape, which are subsequently consumed by State A on pass t + 1.
Over the entire orbit, the cyclic sequence of odd cores visited on the tape
is isomorphic to the standard Syracuse trajectory.


[NOTE 05: Exact Bit-Length Invariant for Synchronized Trajectories]
